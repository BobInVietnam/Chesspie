# CHESSPIE
## A More Tactical Version Of Chess
Normal chess rules still applies (except castling, pawn promotion and en passant haven't been included yet)

But your pieces can activate abilities to gain defense, damage enemies from afar, buff other pieces,... and so on.

Each piece has a set amount of HP, attack power and defense power. Once HP drop to 0, the piece is eliminated.

Eliminate the King for a victory.
